Verifies the operational status, server uptime, API version, and endpoint health of the Apex HR REST API backend.
Response Body: 
Click "Send Request" to fetch live response...
POST http://localhost:5000/api/auth/login
Authenticates employees and administrators. Returns user profile, access role, and JWT token.
Response Body: 
Click "Test Login API" to verify payload...
GET http://localhost:5000/api/employees
Returns list of company employees with department, leave allowance, and current status.
Response Body: 
Click "Get Employees" to view data...
GET http://localhost:5000/api/leaves
Fetches employee leave applications. Supports query filtering by status (Pending, Approved, Rejected).
Response Body: 
Click "Fetch Leaves" to test endpoint...
POST http://localhost:5000/api/leaves
Submits a new leave request. Server calculates requested leave days and stores status as Pending.
Response Body: 
Click "Submit New Leave" to test payload...
PATCH http://localhost:5000/api/leaves/:id/status
Updates leave status (Approved / Rejected / Pending) for admin review workflow.
Response Body: 
Click "Update Status" to update leave request...
GET http://localhost:5000/api/stats
Calculates summary statistics for HR metrics dashboard (Total Employees, Pending, Approved, Rejected).
Response Body: 
Click "Get Dashboard Stats" to view metrics...
